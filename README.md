# 🌱 灵感管理（Inspiration Manager）

一款本地优先的灵感管理桌面应用：随手记录灵感，并把它们逐步孵化成**计划**、**方案**、**项目**。

- 数据全部保存在本机，无网络依赖
- 层级树形结构，灵感一键派生为下级产物
- 自动备份 + 回收站，误删可找回

## 核心概念

每个条目有 4 种类型，构成一条「孵化链路」：

| 类型 | 图标 | 说明 | 可派生为 |
| ---- | ---- | ---- | -------- |
| 灵感 | 💡 | 一闪而过的想法 | 计划 / 方案 / 项目 |
| 计划 | 📝 | 把灵感落成可执行的安排 | 方案 / 项目 |
| 方案 | 🧩 | 具体怎么做 | 项目 |
| 项目 | 🎯 | 正在推进的事 | — |

层级为一对多的树形结构：既支持**逐级派生**（灵感 → 计划 → 方案 → 项目），也支持**跳级派生**（灵感 → 项目）和**独立创建**（任何类型都可直接新建）。

## 功能特性

- **树形列表**：按创建时间排序，可折叠/展开；父条目进回收站后，子条目自动提升为顶层显示
- **详情编辑**：标题、内容、五档星级（★）、标签（芯片式添加/移除）
- **搜索与筛选**：
  - 全文搜索（标题 + 内容）
  - 类型筛选、星级筛选（N 星以上）
  - 标签筛选（可多选）
  - 筛选时自动展开树并保留命中条目的完整层级路径
- **派生下级**：在当前条目下快速生成子条目（仅允许向下派生）
- **回收站**：
  - 删除的条目进入回收站，按删除时间倒序排列
  - 可恢复（自动切回主视图并定位到该条目），或彻底删除（两次确认）
- **多选批量编辑**：勾选多个条目，统一设置星级、统一添加/移除标签
- **数据安全**：
  - 原子写入（临时文件 + 重命名），避免写入中断损坏数据
  - 数据文件损坏时自动挪走保留现场，不覆盖原始文件
  - 启动时自动备份（距上次备份超过 24 小时触发，最多保留 20 份）
  - 一键打开数据文件夹，数据透明可迁移

## 技术栈

- [Electron](https://www.electronjs.org/) 44
- 原生 HTML / CSS / JavaScript（无前端框架、无打包器）
- [electron-builder](https://www.electron.build/)（NSIS 安装版）

安全实践：渲染进程启用 `contextIsolation` + 禁用 `nodeIntegration`，通过 `preload.js` 的 `contextBridge` 暴露最小 API，并配置了 CSP。

## 快速开始

### 环境要求

- Node.js（开发环境验证于 v24.21.0）
- Windows（当前仅打包了 Windows 安装版）

项目已通过 `.npmrc` 配置 [npmmirror](https://npmmirror.com/) 镜像，国内安装 Electron 无需科学上网。

### 安装与运行

```bash
# 安装依赖
npm install

# 启动应用（开发模式）
npm start
```

> 提示：若在自动化终端环境中启动后窗口不出现，检查环境中是否存在
> `ELECTRON_RUN_AS_NODE=1`，需先移除该变量（`env -u ELECTRON_RUN_AS_NODE npm start`）。

### 打包

```bash
# 生成 NSIS 安装版 exe（输出到 dist/）
npm run dist
```

产物：`dist/灵感管理-<版本>-安装版.exe`

- 向导式安装，可选择安装路径，按用户安装无需管理员权限
- 自带卸载程序；卸载时会**彻底删除全部数据**（含备份），如有重要数据请先备份
- 应用未做代码签名，Windows SmartScreen 首次运行可能提示，点「更多信息 → 仍要运行」即可

## 数据存储

数据保存在系统用户目录下（Windows）：

```
%APPDATA%\灵感管理\
├── data.json       # 全部条目（单文件 JSON）
└── backups\        # 自动备份（data-YYYYMMDD-HHmmss.json，最多保留 20 份）
```

可通过应用顶栏「📁 数据文件夹」一键打开。迁移数据时拷贝整个 `灵感管理` 文件夹即可。
